### A7 / A9 的具体核对实例（项目沉淀，供参考不强制）

以下是过往项目沉淀的具体组件约束，**核对方式通用、组件名随项目替换**：

- **入参类型约束**：共享下拉组件（如 `FsSelect`）的绑定值通常为 `String | Number | Array`，**不含 `Boolean`**——布尔 value 会触发 Invalid-prop 告警。不兼容时的二选一：①扩展组件类型（注意 Vue 的 Boolean casting 副作用）；②改传值形态（下拉传 `1/0`，提交时转布尔）。
- **插槽透传约束**：共享表格组件（如 `fs-table`）通常只透传部分具名插槽（如 `bodyCell` / `headerCell`），**不透传 `expandedRowRender`**；需要展开行时直接用底层表格组件（如 `a-table`）。
- **能力开关**：分页、展开行、虚拟滚动、可编辑单元格等，使用前逐一核对目标组件 props / slots，读组件源码或 `.d.ts` 确认后再落笔。

> 若当前项目没有对应组件，跳过实例、只保留「核对组件能力」这一动作；判不准 → 按 full 处理。
